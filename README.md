# 👁️ Antardrishti AI: An Insight

Antardrishti (अन्तर्दृष्टि - "Inner Vision") is an empathetic, multimodal intelligence platform built for the **APAC Builder Challenge**. It bridges human emotional awareness with cutting-edge generative AI, offering introspective guidance, cognitive reasoning, and visual perception.

---

## 🌟 Core Modules

* **🧘 Empathetic Mood Reflection:** An interactive reflective space that blends emotional intelligence (EQ) with structured prompts. It validates emotions with warmth and suggests mindful perspectives for mental clarity and self-growth.
* **📝 Text & Reasoning Analysis:** High-throughput cognitive reasoning powered by Google Gemini, capable of contextual summarization, structured critical inquiry, and analytical synthesis.
* **🖼️ Multimodal Perception:** Direct visual grounding that interprets user-uploaded images alongside analytical queries to deliver practical, multi-layered visual insights.

---

## 🛠️ Architecture & Tech Stack

* **Foundation Model:** Google Gemini (`gemini-3.6-flash`) via the modern `google-genai` SDK
* **Frontend / User Interface:** Streamlit (Python 3.10+)
* **Image Processing:** Pillow (PIL)
* **Deployment & Cloud:** Streamlit Community Cloud with encrypted environment secret management

---

## 🚀 Key Innovation & Alignment

* **Human-First AI Design:** Aligns technology with human emotional depth, moving beyond utilitarian AI into empathetic personal companionship.
* **State-of-the-Art Latency:** Employs the `gemini-3.6-flash` model for balanced multimodal reasoning and rapid turn-around execution.
* **Secure Architecture:** Zero hardcoded credentials, relying strictly on environment-level secret isolation.

## 📖 Local Setup & Execution

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/anamika202/Antardrishti-An-Insight.git](https://github.com/anamika202/Antardrishti-An-Insight.git)
   cd Antardrishti-An-Insight

2. **Install dependencies :**
   pip install -r requirements.txt

3. **Configure Secretes :**
     GEMINI_API_KEY = "your_google_gemini_API_key-here" 

4. **Run the Application:**
     streamlit run app.py
